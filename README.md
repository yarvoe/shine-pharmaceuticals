# Shine Pharmaceuticals — Website MVP

A fast, mobile-first website concept for **Shine Pharmaceuticals** (Central Monrovia), built as an outreach demo by [AIDTECH Liberia](https://aidtech.42web.io/).

## What's inside
- Responsive one-page site (no frameworks, no build step — pure HTML/CSS/JS)
- One-tap WhatsApp ordering / booking / enquiry flows
- Google Maps embed + structured data (LocalBusiness schema)
- Mobile-first performance: compressed WebP imagery, system-friendly fallbacks

## Run locally
Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Deploy
Any static host works (GitHub Pages, Vercel, Netlify). For Vercel: import the repo and deploy — no build command needed.

## Notes
This is a **design demonstration**. Content, prices and opening hours are samples to be replaced with the business's real information before launch. Imagery is either the business's own public photos (credited to the business) or original concept visuals.
